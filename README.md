## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Development uses the public journal CMS by default. To develop against a local Strapi server, set `STRAPI_API_URL=http://localhost:1337` in `.env.local` and start that server separately. `NEXT_PUBLIC_API_URL`, if set, takes precedence.

Run content tests with `node --experimental-strip-types --test tests/content.test.mjs`. With the site running against the public CMS, verify the actual menu links and language-switch destinations with `JOURNAL_TEST_URL=http://127.0.0.1:3000 node --experimental-strip-types --test tests/routes.test.mjs`.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
